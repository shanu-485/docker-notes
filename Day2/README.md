# Day 2 - Docker Images & Containers

## Topics Covered

- Docker Images
- Docker Containers
- Pulling Images
- Running Containers
- Listing Containers
- Stopping Containers
- Removing Containers

## Commands Learned

```bash
docker pull ubuntu
docker images
docker run ubuntu
docker run -it ubuntu bash
docker ps
docker ps -a
docker stop <container-id>
docker rm <container-id>
```

## Outcome

Learned how Docker images and containers work, ran Ubuntu containers, and managed them using Docker commands.
